# AI Human Following Fan

A real-time human tracking system built using YOLOv8, OpenCV, Arduino Uno, and a Servo Motor.

## Features

- Real-time person detection
- Human tracking using YOLOv8
- Smartphone camera integration using DroidCam
- Servo motor control support
- Low-cost AI and IoT project

## Technologies Used

- Python
- OpenCV
- YOLOv8
- Arduino Uno
- SG90 Servo Motor
- DroidCam

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python person_tracker.py
```

## Project Workflow

Phone Camera → DroidCam → YOLOv8 → Person Tracking → Arduino Uno → Servo Motor
